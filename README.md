# ☕ Hifza's Cafe 🩷

A beautiful and responsive café website built with PHP, MySQL, HTML, CSS, and JavaScript.

Hifza's Cafe is a full-stack café website designed with a soft pink and white aesthetic. Customers can explore the menu, view individual items, add items to a shopping cart, place orders, and send messages through the contact form.

## ✨ Features

- 🏠 Home page
- 🩷 About page
- ☕ Menu with 32 café items
- 🔎 Individual item details
- 🛒 Shopping cart
- ➕ Quantity controls
- 📝 Order placement system
- 💌 Contact form
- 🗄️ MySQL database integration
- 📱 Responsive design
- 🎀 Soft pink and white café-themed interface
- 🔔 Professional success and notification messages

## 🍽️ Menu Categories

The website includes:

- ☕ Coffee
- 🫖 Tea
- 🥐 Breakfast
- 🥪 Sandwiches & Wraps
- 🍩 Donuts
- 🍰 Cakes
